# Family AI 1.0 (PWA)

Семейный помощник в виде устанавливаемого веб-приложения.

## Публикация через GitHub Pages
1. Создайте публичный репозиторий `family-ai`.
2. Загрузите **содержимое этой папки** в корень репозитория (не ZIP-файл целиком).
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Откройте опубликованный HTTPS-адрес сайта.
5. В Chrome на Android выберите меню → «Установить приложение» (или «Добавить на главный экран», если установка недоступна).

## Что входит
- `index.html` — существующее приложение Family AI, без переписывания диалогов
- `manifest.webmanifest` — название и настройки установки
- `sw.js` — кэширование оболочки приложения для офлайн-запуска
- `icons/` — иконки 192×192 и 512×512

## Ограничения
- PWA-установка и Service Worker не работают при открытии `index.html` как локального `file://` файла: нужен HTTPS (например, GitHub Pages).
- Интернет-поиск и онлайн-функции без сети не работают.
- Данные чатов и списков хранятся локально в браузере/установленном приложении и не синхронизируются между устройствами.
- Это бета-версия: поведение всех функций на Android ещё не протестировано.
- При обновлении меняйте имя CACHE_NAME в `sw.js`.
